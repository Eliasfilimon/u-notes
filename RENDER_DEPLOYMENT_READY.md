## ✅ Environment Variables Setup

Before deploying to Render, set these environment variables in your Render dashboard:

### Required
```
DJANGO_SECRET_KEY=<auto-generated by Render>
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=your-app.onrender.com
```

### Security (Production)
```
DJANGO_SECURE_SSL_REDIRECT=True
DJANGO_SESSION_COOKIE_SECURE=True
DJANGO_CSRF_COOKIE_SECURE=True
DJANGO_SECURE_HSTS_SECONDS=31536000
DJANGO_SECURE_HSTS_INCLUDE_SUBDOMAINS=True
DJANGO_SECURE_HSTS_PRELOAD=True
DJANGO_SECURE_CONTENT_TYPE_NOSNIFF=True
DJANGO_SECURE_BROWSER_XSS_FILTER=True
DJANGO_X_FRAME_OPTIONS=DENY
```

### Database (PostgreSQL on Render)
```
DATABASE_URL=<auto-provided by Render>
```

### Optional
```
OPENAI_API_KEY=<your key if using AI features>
```

## 📋 Deployment Steps

### Step 1: Connect GitHub Repository
1. Go to https://dashboard.render.com/
2. Click "New" → "Web Service"
3. Connect your GitHub repository
4. Select the repository containing u-notes

### Step 2: Configure Service
1. **Name**: `u-notes` (or your preferred name)
2. **Runtime**: Python 3.12 (Render will detect from runtime.txt)
3. **Build Command**: Will use render.yaml settings
4. **Start Command**: Will use render.yaml settings

### Step 3: Set Environment Variables
1. In Render dashboard, go to your service
2. Click "Environment"
3. Add all variables from the "Security" section above
4. Render auto-generates `DJANGO_SECRET_KEY`

### Step 4: Configure Database
1. In Render dashboard, click "Database"
2. Create new PostgreSQL instance
3. Render will provide `DATABASE_URL`
4. Add it to Environment Variables

### Step 5: Deploy
1. Click "Deploy" in Render dashboard
2. Watch the build logs
3. Confirm "Deployed" status
