# 🚀 Complete Render Setup Guide: PostgreSQL, Environment Variables & Auto-Deployment

## Part 1: Set Up PostgreSQL Database on Render

### Step 1: Create PostgreSQL Database

1. **Go to Render Dashboard:**
   - URL: https://dashboard.render.com/
   - Log in with your account

2. **Create Database:**
   - Click **"New +"** (top left)
   - Select **"PostgreSQL"**
   - Fill in details:
     ```
     Name: u-notes-db
     Database: u_notes
     User: u_notes
     Region: (choose closest to your location)
     PostgreSQL Version: 15 (recommended)
     ```

3. **Review and Create:**
   - Click **"Create Database"**
   - Wait for database to initialize (1-2 minutes)
   - You'll see a green checkmark when ready

4. **Copy Connection Details:**
   - After creation, click on the database
   - Look for **"Connections"** section
   - You'll see:
     ```
     Host: <hostname>
     Database: u_notes
     User: u_notes
     Password: <auto-generated>
     Port: 5432
     ```
   - **IMPORTANT:** Copy the **"Internal Database URL"** (not external)
   - It looks like: `postgresql://u_notes:<password>@<host>:5432/u_notes`

## Part 2: Create Web Service & Set Environment Variables

### Step 1: Create Web Service

1. **Click "New +"** → **"Web Service"**

2. **Select Repository:**
   - Choose "GitHub"
   - Authorize Render to access GitHub (if first time)
   - Select your `u-notes` repository
   - Click **"Connect"**

3. **Configure Service:**
   ```
   Name: u-notes
   Region: Same as database region (important!)
   Branch: main
   Runtime: Python 3.12 (auto-detected from runtime.txt)
   Build Command: (auto-detected from render.yaml)
   Start Command: (auto-detected from render.yaml)
   ```

4. **Click "Create Web Service"**

### Step 2: Add Environment Variables

After web service is created:

1. **Go to Your Web Service Page:**
   - You should see it loading
   - Wait for the initial build (3-5 minutes)

2. **Click "Environment" (left sidebar)**

3. **Add Variables (Click "+ Add Environment Variable"):**

   **Critical Variables:**
   ```
   DJANGO_SECRET_KEY = (Render auto-generates, DO NOT CHANGE)
   DATABASE_URL = postgresql://u_notes:PASSWORD@HOST:5432/u_notes
   DJANGO_DEBUG = False
   DJANGO_ALLOWED_HOSTS = your-app.onrender.com
   ```

   **Security Variables:**
   ```
   DJANGO_SECURE_SSL_REDIRECT = True
   DJANGO_SESSION_COOKIE_SECURE = True
   DJANGO_CSRF_COOKIE_SECURE = True
   DJANGO_SECURE_HSTS_SECONDS = 31536000
   DJANGO_SECURE_HSTS_INCLUDE_SUBDOMAINS = True
   DJANGO_SECURE_HSTS_PRELOAD = True
   DJANGO_SECURE_CONTENT_TYPE_NOSNIFF = True
   DJANGO_SECURE_BROWSER_XSS_FILTER = True
   DJANGO_X_FRAME_OPTIONS = DENY
   DJANGO_CSRF_TRUSTED_ORIGINS = https://*.onrender.com
   ```

   **Optional:**
   ```
   OPENAI_API_KEY = (only if you have this)
   ```

4. **Save Changes:**
   - Click **"Save Changes"**
   - Service will automatically restart
   - Build will start with new variables

## Part 3: Auto-Deployment from GitHub

### How Auto-Deployment Works

Render automatically deploys when you:
1. **Push to main branch** (automatically)
2. **Manually trigger** in dashboard (optional)
3. **Scheduled rebuilds** (optional)

### Setup Auto-Deployment (Default)

✅ **Already Enabled!**

When you:
```bash
git add .
git commit -m "Your message"
git push origin main
```

Render automatically:
1. Detects the push to GitHub
2. Pulls your code
3. Runs build command
4. Runs migrations
5. Restarts service
6. Deploys new version

### Watch Deployment Progress

1. **In Render Dashboard:**
   - Click your web service
   - Click **"Logs"** tab
   - You'll see real-time build logs:
     ```
     [Building]
     Building image...
     Installing dependencies...
     Running migrations...
     Collecting static files...
     [Deploy]
     Service is live!
     ```

2. **Check Status:**
   - Green badge = "Live" = Ready
   - Yellow badge = "Building" = In progress
   - Red badge = "Error" = Check logs

## Part 7: Troubleshooting Auto-Deployment

### Issue: Deployment doesn't trigger

**Solution:**
```bash
# Verify you pushed to main branch
git branch  # Should show * main

# Verify Render sees GitHub
Dashboard → Settings → GitHub Integration
→ Should show "Connected"

# Manual trigger
Dashboard → Web Service → "Redeploy Latest"
```

### Issue: Build fails with DATABASE_URL error

**Solution:**
1. Check DATABASE_URL is set in Environment
2. Copy from database page, not from terminal
3. Format must be exact:
   ```
   postgresql://USER:PASSWORD@HOST:PORT/DATABASE
   ```
4. No spaces or special characters

### Issue: App loads but features don't work

**Solution:**
1. Check DJANGO_ALLOWED_HOSTS includes your domain
2. Check DJANGO_DEBUG = False
3. Check all environment variables saved
4. View logs: Dashboard → Logs → find errors

### Issue: Static files or CSS not loading

**Solution:**
1. Already handled by WhiteNoise
2. Check build logs for "collectstatic" success
3. Hard refresh browser (Ctrl+Shift+R)
4. Check DJANGO_ALLOWED_HOSTS
